# Botanica – Minimal Sandbox

This branch pares Botanica down to a single interactive diorama so you can rebuild the gameplay loop step by step.

## Included
- Vite + Three.js scaffold with orbit controls
- One `GrassPodule` that combines a grass ground plane and stone pavers
- Lightweight lighting setup to showcase the scene

## Getting Started
```bash
npm install
npm run dev
```

Point your browser at the dev server and start layering new mechanics on top of the minimal sandbox.
